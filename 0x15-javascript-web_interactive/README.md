# W6 | JavaScript - Web jQuery Part 1

## Description

This project introduces the use of **jQuery**, a JavaScript library that simplifies DOM manipulation, event handling, and interaction with HTML elements.

The goal is to learn how to select HTML elements, modify their content and styles, handle user events, and update web pages dynamically using jQuery.

## Learning Objectives

By completing this project, you should be able to:

- Understand the basics of jQuery.
- Select HTML elements using jQuery selectors.
- Modify HTML elements and their content.
- Change CSS styles dynamically.
- Handle user interactions and browser events.
- Add, remove, and manipulate DOM elements.
- Use jQuery to make web pages interactive.
- Understand the difference between JavaScript and jQuery.
